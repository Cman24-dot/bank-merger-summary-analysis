# Bank Merger Summary Analysis

Interactive dashboard comparing FDIC bank mergers against non-merging peer banks in the same asset band and time window (3 / 6 / 12 months). Built to answer whether post-deal asset changes look unusual relative to peers, not just a static median.

Public FDIC / call-report style inputs only. Single-page HTML/JS app (no backend). Built with Claude Code.

Open index.html locally, or use the GitHub Pages link from this repo.
